Code of Conduct

Our Commitment

MultiStudio is an open-source project dedicated to building a reliable, accessible, and user-friendly multistreaming application.

We are committed to creating a welcoming, respectful, and inclusive environment for everyone participating in the project.

We welcome contributors regardless of experience level, background, identity, or technical expertise.

Expected Behavior

All community members are expected to:

- Treat others with respect, kindness, and professionalism.
- Use welcoming and inclusive language.
- Respect different viewpoints and experiences.
- Give and receive constructive feedback.
- Focus on technical ideas rather than personal criticism.
- Help new contributors understand the project.
- Respect the time and effort of other contributors.
- Take responsibility for mistakes and work toward resolving conflicts.
- Follow the project's contribution and security guidelines.

Constructive disagreement is welcome when discussions remain respectful and focused on improving MultiStudio.

Unacceptable Behavior

The following behavior is not tolerated:

- Harassment, intimidation, bullying, or discrimination.
- Hate speech or derogatory comments.
- Personal insults or targeted attacks.
- Threats of violence.
- Unwanted sexual attention or inappropriate sexual content.
- Deliberate disruption of discussions or development activities.
- Publishing another person's private information without permission.
- Repeated trolling, spamming, or malicious behavior.
- Retaliation against individuals who report misconduct.
- Knowingly submitting malicious code or attempting to compromise the project.

Scope

This Code of Conduct applies to all official MultiStudio community spaces, including:

- GitHub issues and pull requests.
- GitHub Discussions.
- Code reviews.
- Project documentation.
- Official community communication channels.
- Project-related events and meetings.

It also applies when someone is officially representing MultiStudio in public spaces.

Reporting Violations

If you experience or witness behavior that violates this Code of Conduct, please report it privately to the project maintainers.

Use a private moderation contact method published in the repository or its official community channels.

Please include, when appropriate:

- A description of the incident.
- Where and when it occurred.
- Relevant links or screenshots.
- Any additional context that may help the maintainers understand the situation.

Reports will be handled with discretion. Information will be shared only as reasonably necessary to review and address the incident.

Do not use public GitHub issues to disclose sensitive personal information.

Security vulnerabilities should instead be reported according to "SECURITY.md" (SECURITY.md).

Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing acceptable behavior within official MultiStudio community spaces.

Maintainers may:

- Request that inappropriate behavior stop.
- Edit, hide, or remove inappropriate content.
- Close or lock disruptive discussions.
- Reject contributions that violate community rules.
- Issue warnings.
- Temporarily or permanently restrict participation.

Enforcement decisions should consider the severity, context, and frequency of the behavior.

Enforcement Guidelines

1. Correction

For minor or unintentional violations, maintainers may provide a private or public reminder explaining the expected behavior.

2. Warning

For more significant violations, maintainers may issue a formal warning and request that the behavior not be repeated.

3. Temporary Restriction

For repeated or serious violations, maintainers may temporarily restrict participation in project spaces.

4. Permanent Restriction

For severe, threatening, or persistent misconduct, maintainers may permanently restrict participation.

These measures are guidelines rather than mandatory sequential steps. Serious incidents may require immediate action.

Fairness and Accountability

Maintainers should apply these rules consistently and avoid conflicts of interest when reviewing reports.

Where practical, a report involving a maintainer should be reviewed by another maintainer.

Individuals involved in an incident should be treated fairly, and reports should not automatically be considered proof of misconduct.

Positive Community Culture

We encourage community members to:

- Share knowledge and help others learn.
- Welcome first-time contributors.
- Recognize useful contributions.
- Write clear and respectful code reviews.
- Document technical decisions.
- Collaborate openly and constructively.
- Support accessibility and usability improvements.
- Help make MultiStudio better for everyone.

Changes to This Policy

This Code of Conduct may be updated as the MultiStudio project and community grow.

Changes should be documented in the repository and communicated through appropriate project channels.

Contact

For community conduct concerns, contact the project maintainers through an official private reporting channel when one becomes available.
